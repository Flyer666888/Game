# 开场敌人显示与护阵执事

## SteamVR 入口

1. 连接头显和两只手柄，打开 `Run_VR_Demo.cmd`。
2. 进入场景后，敌人会先站在前方等待。待战阶段尚不能造成伤害。
3. 头显和双手柄追踪稳定后，倒计时 3 秒开始战斗。未开始时查看视野内的状态提示。
4. 若需要在编辑器制作，使用 `Run_VR_Editor.cmd`，然后选择 **VR 预览**。

“模拟”模式用于观察场景，不会生成正常受控玩家。原来敌人等待玩家启动，因此这个入口可能只显示空场；本次给准备阶段增加了敌人呈现和入口提示。

这两个启动入口只为其启动的 UE 进程指定 SteamVR。直接打开 `.uproject` 会使用电脑设置的默认 OpenXR 运行时；最近日志中的默认运行时是 Oculus。

## 护阵执事独立场景

打开 `Run_GuardCaptain_Demo.cmd`，按 **G** 开始：

- 第一波：一名护阵执事。
- 第二波：一名护阵执事和一名御符弟子。
- 执事正面举起阵盾时可阻挡攻击；连续消耗护势可破防，也可绕到侧后方攻击。
- 破防后有短暂失衡窗口。重击蓄力时会撤下阵盾，注意闪避或举镜。
- **WASD** 移动，鼠标转向，**左键** 挥剑（伤害 10），**E** 刀气，**右键** 举镜。
- **R** 返回本波检查点，**Esc / P** 暂停，**Alt+F4** 退出。

当前仍使用已有角色和动画，阵盾为功能示意美术。入口依赖本机 UE5.8 和完整工程，不是打包后的独立 EXE。

本批记录编译、资产保存和初始画面。真实头显中的朝向、手柄交战，以及执事的攻防节奏仍需用户试玩确认。
