《逆鳞》关卡遭遇与生命恢复设计 V01

本版本将“敌人何时出现、出现多少”落实为区域触发与前置依赖驱动的波次遭遇系统，将“血条奖励”落实为战斗表现驱动的生命恢复机制与精英首杀固定恢复补给。范围仅包含这两项玩法及其必要反馈、重试和持久化约束。

版本与入口

- 项目：D:\game design\experiment。
- 独立玩法地图：/Game/ReversedScale/Maps/L_NilinGameplayV01。
- 源白模：/Game/ReversedScale/Maps/L_NilinBlockoutV10，保留原地图。
- 桌面启动：项目根目录 Run_Gameplay_Demo.cmd，无需头显。
- 配置依据：本目录 EncounterConfig.json 及已生成的关卡、波次数据资产。
- 本独立静态白模使用随地图保存的烘焙导航，关闭加载时强制重建，避免启动时取得尚未完成的导航。以后修改地面、台阶、障碍或出生点，需要重新构建导航并检查路径。

1. 遭遇调度与敌人配置

核心术语

遭遇段（Encounter Stage）：具有独立触发区域、前置条件、预警、若干波次和重试入口的战斗单元。全关卡共 16 段。

波次（Wave）：一组预定敌人及出生规则。全关卡共 27 波。波内分批出生；“本波总人数”与“同时存活上限”分别控制战斗持续时间和瞬时压力。

区域触发（Area Trigger）：受控且存活的玩家进入作者设置的范围后启动检查。只有前置遭遇已完成，才进入 2 秒预警。同一时间仅运行一个遭遇，已完成段不重复触发。

存活并发上限（Alive Cap）：限制同一波在场的活敌数量。本版全流程峰值不超过 4；岩台段为 2；宗师本体和 Boss 为 1。存活名额空出后，继续出生本波尚未出现的敌人。

时间节奏与失败处理

- 每段预警：2 秒，以游戏时间计时。
- 普通敌人出生间隔：0.65 秒；宗师本体、Boss 单人波为立即出生。
- 清波后休整：普通多波段通常为 2.5 秒；镇符、丹火宗师护卫波到宗师本体为 3 秒。最后一波清空后直接完成该段。
- 出生位置被阻挡时，控制器按 0.5 秒间隔自动重试，最多重试 24 次；耗尽后明确进入失败状态，避免悄悄漏掉敌人仍判通关。
- 玩家死亡或遭遇失败后，R 返回当前段入口、恢复资源并从该段第一波重来。重试不回滚已完成段，不重复发放已领取的宗师补给。
- 段间移动时死亡，R 将玩家恢复至安全入口；存活且无当前战斗时不会提供免费回血重置。
- 1–4 为场景检查跳点，预警、交战及失败待重试期间禁用；跳点不会修改通关状态或绕过依赖。

岩台远程敌人

三处栈道使用凸起石台承载持符弟子，每处 2 名。岩台版本启用固定阵位，保留高低差压制，不使用突兀的桥亭承载射手。射击需要射程与视线成立；施法前摇当前为 1.2 秒，攻击距离 28 米，弹体速度 10 米/秒。普通场地持符弟子继续使用可移动版本。

2. 生命状态反馈与恢复奖励

化劲回元：战斗表现驱动的生命恢复

设计目的：让防守时机成为可学习的生存手段，鼓励玩家观察攻击预兆、在命中前举盾，而不是持续举盾等待自动回血。

规则：玩家受伤且存活时，每 3 次有效精准格挡触发一次恢复，回复最多 10 点生命，并消耗本次 3 格蓄积。恢复受生命上限约束，不产生溢出生命，也不复活玩家。

有效事件：以战斗结算器确认的精准格挡结果为准，必须属于当前玩家，并具有有效攻击与结算身份。普通格挡不增加蓄积；同一次攻击即使触发重复碰撞或重复广播，也只结算一次奖励。当前精准窗口为举盾后的 0.18 秒，还需满足攻击可被精准格挡、格挡方向与接触条件。

蓄积约束：3 次不要求连续，中间受伤或普通格挡不会自行清空。满血时不增加蓄积，达到满血、死亡、本段重试会清空进度；暂停期间不发放恢复。一次触发后从 0 重新积累。

反馈：生命条表现实际值与变化过渡；左上显示“化劲回元”三格进度。有效精准格挡时显示“回元蓄积”，满血时提示“生命充盈”；触发恢复时显示实际恢复量。

宗师首杀补给：精英首杀固定恢复奖励

设计目的：在四场精英考验后提供可预期的资源回补，支持玩家继续挑战山顶，同时保留“现在领取还是受伤后再领取”的选择。

规则：御风桥每位宗师首次被有效击败时，生成一份该宗师专属的回复灵气。护卫死亡不触发宗师奖励。存活且受伤的玩家靠近拾取，可恢复最多 25 点生命；每份只可领取一次。

拾取约束：满血、死亡、非玩家或暂停状态不能消耗补给。满血经过后，补给仍保留；受伤后离开再靠近可重新触发拾取。补给不能令生命超过上限，也不能作为复活物。

防重复领取：以同一局的 Run 身份加宗师身份记录“已击败”和“已领取”，分别管理。领取记录先持久化成功，才发放恢复；失败时保留补给。当前段重试、重载同一 Run、恢复同一 Run 的较早存档，都不会抹去已领取记录。已击败但未领取的补给可按记录恢复；新 Run 独立计数。

持久化边界：上述约束针对游戏内同一 Run 的重试与回档；不宣称防止用户删除、修改外部存档文件。当前地图不提供完整的存档管理界面。

区分血条与奖励规则

血条负责呈现当前生命与变化；化劲回元由有效精准格挡计数触发，宗师补给由首杀及拾取触发。本版本没有将“打掉 Boss 某一段血”设为奖励条件。

桌面操作与验证边界

WASD 移动，鼠标转向，左 Shift 加速，左键挥剑，右键举盾，E 剑气，P/Esc 暂停，Tab 切换鼠标捕获，R 当前段重试。1–4 检查跳点依次为山门、中段休整节点、御风桥、山顶。

本说明描述代码和配置意图，不替代最终测试结论。编译、自动化、地图导航与完整运行检查应分别查看本目录对应报告。VR 头显、手柄输入、VR 性能及完整人工通关体验尚未验收。
