# 持剑弟子战斗 Demo

入口：项目根目录的 `Run_SwordDuel_Demo.cmd`，无需 VR 设备，需要本机 UE 5.8 编辑器。

## 操作

| 按键 | 操作 |
| --- | --- |
| WASD / 鼠标 | 移动 / 转动视角 |
| G | 开始或停止两个持剑弟子的交战 |
| 鼠标左键 | 挥刀，伤害 10 |
| E | 发射刀气，伤害 15 |
| 按住鼠标右键 | 举起护心镜，拦截正面的刀刃或弹丸 |
| 弹丸抵达时按右键 | 尝试 0.18 秒精准反弹窗口 |
| F | 开始或停止远处发射器；默认关闭 |
| Esc / P | 暂停或继续 |
| R | 恢复玩家、敌人及发射器，清理弹丸和攻击名额；交战重新关闭 |
| Alt+F4 | 退出 |

进入场景时敌人和发射器均不攻击，可以先观察模型。按 G 开始剑士练习；敌人接近后会显示 INCOMING 并蓄力，之后挥刀、收招。R 可重复开始这一小型战斗。

玩家生命 100、护镜耐力 100。弟子当前是 30 生命的调试参数，单次近战伤害 10，需三次有效命中；敌人挥刀伤害 10。这个调试场景尚未切换资料包“一刀击败杂兵”的最终关卡参数。

近战普通格挡消耗 20 耐力，弹丸普通格挡消耗 12，持续举镜每秒消耗 6。破镜后应松开右键；暂停会降下护镜，继续后重新按右键举镜。

两名弟子击败后可继续 F 发射器反弹练习。HUD 的完整练习目标为击败两名弟子并反弹至少一发弹丸；若提前击败发射器而未反弹，按 R 重来。

## 本批范围

复用已修正的脸部、脚部、刀柄，以及受击和死亡动作。步行由导航驱动，动画已去掉较大的根位移并收敛抬脚；攻击使用提供的剑士动作，伤害需同时满足动画通知和导演批准的攻击窗口。

源码编译、资产保存和初始呈现分别记录在 `Docs/AI/State.md`。实际追击、命中、格挡、暂停恢复及重复交战等待用户试玩；尚未进行真实 VR 验收。当前入口调用编辑器的独立游戏模式，尚未打包为独立 EXE。
