第一关：山门外防 / 演武石院
参考的主要构成是巨大可穿行门框、龙旗、石狮、远近分层的弟子站位和宽阔石铺庭院。
对应建筑：开放三间山门、厚重石柱/木梁、简单守门廊与外围短墙。演武前院以低侧房、兵器架和旗列形成训练/守卫用途，主战斗面保持空旷。
识别轮廓：高大矩形门框与竖向幡旗。主材为灰石、深木与靛蓝旗面。门必须有可通行开口，不能长期闭门阻断主路。

第二关：开放炼丹亭 / 守护炉坛
严格恢复参考中的前后关系：
近侧玩家站位 → 前方约4m挚友/解救法阵 → 独立的平整防守间距 → 中轴正后方巨型炼丹炉 → 开放高檐亭架。
撤销v05的侧置炉台。炉位于同一上层丹院的后中，不能进入法阵、挡在挚友前方或变成院角的小摆设。
原封闭丹殿改为开放式高檐炼丹亭/工坊。柱列与低配房退到两侧，后顶浅退，确保总览仍能辨认大炉，也为炉居后保留合理建筑空间。右侧配房缩短/开敞，保留望峰方向。
法阵、炉、玩家站位分别清楚，不让双手防御目标与建筑装饰混淆。前向两侧入口保留敌方预警与施法位；不要求转身保护背后。
识别轮廓：高亭架下的巨型圆炉与前方低圆阵。材质以铜炉、炉火暖色、深木柱架为主。

第三关：峰顶石桥战台 / 封山剑阵壁
参考的主要构成是纵深石桥、Boss后方大立式圆环阵壁、两侧悬剑与开敞天空。
撤销与前两关重复的木构主殿。改为峰顶宽阔平战台、短石桥式轴线、后方石制剑壁/封山门、两侧石阙与幡旗。巨大立式圆阵保留为最强识别形，石阙只辅助其建构。
实体峰顶岩体、平台边缘和高处悬剑冠仍是低处可见的目标。Boss位置在前向远端，弹幕前场留空；桥式战台不是狭窄走索。约28m净空和约10mBoss距离均待灰盒校验。
识别轮廓：无主殿大屋顶的立式圆阵与石桥轴线。材质以旧石、暗金属、局部阵光为主。

保持的整体关系
低山门 → 连体半山双层院 → 右侧桥阶 → 独立实体峰顶，仍为三组主台地、四层院坪。保留一株主巨松、云海下沉、连续栏边、平落台及平整战斗面。
主要构筑物正面继续朝总览图观察者。望峰开口需避让屋檐与树冠。三关通过建筑类型、轮廓和空间用途区分；总览统一光照以方便比较空间，参考中昼/暮/夜可留待各关实机氛围设计。
