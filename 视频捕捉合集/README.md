# 📷 摄像头互动小课堂

一套面向学生课堂的**摄像头交互小游戏底座**,包含六个可独立运行、可二次开发的网页 demo:

| 页面 | 文件 | 识别技术 | 玩法 |
|---|---|---|---|
| 菜单首页 | `index.html` | — | 六个游戏的入口 |
| 手势识别 | `gesture.html` | MediaPipe Hands(21 个手部关键点) | 实时手势识别(拳头/剪刀/布/点赞/OK 等 8 种)+ 和电脑猜拳对战 |
| 表情识别 | `expression.html` | MediaPipe Face Mesh(468 个面部关键点) | 微笑/张嘴/眨眼/挑眉四个"表情能量条" + 60 秒表情配对挑战赛 |
| 全身动作 | `body.html` | MediaPipe Pose(33 个身体关键点) | 举手/深蹲等动作检测 + 挥动双手摘星星挑战赛 |
| 手势算术 | `math.html` | MediaPipe Hands(21 个手部关键点,双手) | 屏幕出 10 以内加减法,学生用手指比出答案(握拳=0,双手 0~10),保持 1 秒自动交卷判题 |
| 表情识别 | `meme.html` | MediaPipe Face Mesh(468 个面部关键点) | 「轻松崩住」:屏幕不断投喂抽象表情包,玩家必须保持面无表情,一笑"崩值"上涨,涨满或逃离摄像头即失败,比拼存活时间 |
| 手掌钢琴 | `piano.html` | MediaPipe Hands(21 个手部关键点,双手) | 画面上方有一排琴键(do~si,共 7 个白键),彩色音符从屏幕下方向上飘,手掌向上顶到金色触发线按下对应颜色的键,跟着节拍弹完《小星星》;支持自动演示 |

**所有识别都在浏览器本地完成,摄像头画面不会上传到任何服务器,不需要联网。**

---

## 一、如何启动(3 步)

1. 把整个 `摄像头交互` 文件夹拷贝到上课的电脑上;
2. 双击 **`一键启动.cmd`** —— 它会自动启动本地服务器并打开浏览器;
3. 浏览器弹出摄像头授权询问时,点击 **允许**。

> 请使用 **Chrome 或 Edge** 浏览器(较新版本)。
>
> ⚠️ 不要直接双击 HTML 文件打开!浏览器安全策略只允许 `http://localhost`
> 这样的地址访问摄像头,直接打开(file:// 地址)会显示"无法打开摄像头"。

## 二、电脑需要装什么?

`一键启动.cmd` 会按顺序尝试以下三种启动方式,**有一个就行**:

1. **Python**(推荐):从 https://www.python.org/downloads/ 下载,
   安装时务必勾选 **Add Python to PATH**;
2. **Node.js**:从 https://nodejs.org/zh-cn 下载 LTS 版即可。

各个页面本身零依赖,识别库(AI 模型 + 运行时,约 90MB)已经全部下载在
`libs/` 文件夹里,**课堂现场不需要联网**。

## 四、给老师的课堂小贴士

- **光线**:识别对光线敏感,避免学生背对窗户逆光坐;夜间教室保证面部有光。
- **距离**:手势/表情页半身入镜即可;全身页需要**后退一步**,让肩膀(最好到大腿)入镜。
- **性能**:大部分页面角落会显示 FPS。如果低于 15 FPS 会明显卡顿,可以关掉
  学生机上的其他程序,或在代码里把 `modelComplexity` 从 1 改成 0(轻量模式)。
- **首次加载**:每个页面第一次打开要加载几秒到十几秒模型(第二次起就快了),
  建议课前把六个页面都先打开一遍"预热"。
- **轻松崩住课前热场**:这个游戏最适合投在大屏上全班一起玩——
  一个同学上台绷脸,底下全班起哄,笑点密集,注意控制课堂纪律 :)
- **摄像头被拒绝**:点浏览器地址栏左侧的小图标 → 允许摄像头 → 刷新页面。

## 五、二次开发指引(带学生改代码)

所有 demo 页面都是**单文件**的:HTML 结构、CSS 样式、JavaScript 逻辑全部写在
一个文件里,注释齐全,按"第 1 ~ 6 部分"分节,学生用记事本/VS Code 打开就能改。
几个适合课堂练手的改造点:

**gesture.html**
- `recognizeGesture()` 里的手势规则是纯"如果…那么…"逻辑,
  让学生添加一个新手势(比如"摇滚 🤘 加一根食指" or 六手势);
- 改 `STABLE_FRAMES` 感受"防抖"对识别体验的影响;
- 把猜拳改成"三局两胜制";
- 改 `COUNTDOWN_STEP` 调整猜拳倒计时节奏;
- 第 6 部分的 `beep(频率, 时长…)` 用代码直接合成音效,
  改改频率数字就能创作自己的输赢音效(不需要任何音频文件)。

**expression.html**
- 顶部 `TH` 阈值表控制"多大算张嘴/微笑",改一改立刻见效;
- 给挑战赛加新目标表情(比如"闭嘴 + 挑眉"组合);
- 把 HOLD_MS 调大/调小,感受难度变化;
- 第 6 部分用 `beep()` 合成音效:得分沿五声音阶步步高升,改 `SCALE`
  数组就能换音阶(各个游戏页的音效写法完全一样,方便对比学习)。

**body.html**
- 动作判定只有几个 if 判断(看注释里的编号表),
  让学生添加"单脚站立""双手平举成 T 字"等新动作;
- 删掉"鼻子也能玩"那一行,对比游戏难度;
- 改 `STAR_COUNT`、`GAME_SECONDS`、星星大小,自定义游戏节奏;
- 音效和另外两页同款:`sndCatch(n)` 让摘到第 n 颗星星时音阶上行。

**math.html**
- 顶部 `TOTAL_QUESTIONS`(一轮几题)、`HOLD_MS`(保持多久交卷)、
  `STABLE_FRAMES`(防抖帧数)三个常量,改一改手感立刻不同;
- `genQuestion()` 里改出题范围:把 10 换成 5(学前班)或挑战 20 以内
  ——先让学生讨论:两只手最多比到 10,20 以内怎么比?
- 答错 2 次后会出现"小抄"提示,规则在 `hintFor()` 里,可以改成
  摆小棒、数轴等别的提示方式;
- `submitAnswer()` 的评星标准(9 题三星 / 7 题两星…)在 `endGame()` 里。

**meme.html(轻松崩住)**
- 顶部 `GAME` 参数表一改难度立刻变:崩值涨速 `SMILE_RATE` / `OPEN_RATE`、
  每级换图间隔 `SWITCH_SECONDS`、升级节奏 `LEVEL_SECONDS`;
- 往 `memes/` 文件夹里丢几张自己的表情包,把文件名加进
  `MEME_FILES` 数组(一行一张),课堂笑点自己定制;
- `TAUNTS` 数组是游戏中飘过的"挑衅弹幕",想多欠揍就多写几句;
- 判定思想和 expression.html 的"挑眉基准"一脉相承:开局 3 秒先记录
  你不笑时的嘴型做基准,之后"和自己比"。改 `SMILE_DELTA` 感受灵敏度差异。

**piano.html(手掌钢琴)**
- 顶部"手感参数"区一改难度立刻变:`FALL_SEC`(音符下落秒数,越小越难)、
  `BEAT_MS`(歌曲速度)、`HIT_PERFECT / HIT_GOOD`(判定窗口宽严);
- `SONG` 数组就是乐谱,每个元素 = [琴键名, 拍数, 歌词],
  照着简谱就能换一首新歌(比如《两只老虎》《欢乐颂》);
- `PIANO_PARTIALS` 泛音表决定钢琴音色:改倍频和音量听听区别,
  全靠代码合成,同样不需要任何音频文件;
- 手掌怎么"按琴键"在 `updateHand()` 里:越过触发线 = 按下,
  退回 36 像素才算离开(迟滞防抖),让学生改成"指尖触发"对比手感。

**通用**
- 改颜色/字体/背景:每个文件的 `<style>` 块都有中文注释;
- 骨架颜色、粗细在 `onResults()` 的绘制代码里。

## 六、常见问题(FAQ)

| 现象 | 原因与解决 |
|---|---|
| 打不开摄像头 | ① 浏览器没授权 → 地址栏左侧图标里允许;② 直接双击了 HTML → 用「一键启动.cmd」;③ 摄像头被微信/钉钉/腾讯会议占用 → 关掉它们 |
| 双击 HTML 直接打开,一直卡在"初始化中"转圈 | file:// 页面被浏览器禁止加载模型和摄像头(现在页面会直接弹出提示)。请双击「一键启动.cmd」,从 localhost 地址打开 |
| 双击 cmd 后一闪而过 | 用"右键 → 编辑"打开查看报错;多半是没装 Python/Node,见第二节 |
| 启动时提示端口被占用 | 启动脚本会**自动关闭**上次残留的本项目服务器(python/node);若端口被**其他程序**占用(比如开发工具),脚本不会强杀它以免丢失数据,而是自动换一个空闲端口(8001~8020)。想强制清掉任何占用进程,把 `一键启动.cmd` 里的 `set FORCE_KILL=0` 改成 `1` |
| 为什么 cmd 里的提示是英文 | Windows 批处理按系统 ANSI 编码(中文系统是 GBK)解析脚本文件,UTF-8 中文会乱码甚至报错,所以脚本内容全部使用 ASCII 英文;文件名和课堂提示不受影响,中文说明以本 README 为准 |
| 页面显示"模型加载失败" | 检查 `libs/` 文件夹是否和 HTML 在一起(拷贝时别漏) |
| 识别很卡(FPS 低) | 见"课堂小贴士":关其他程序,或把 `modelComplexity` 改成 0 |
| 识别不准 / 频繁丢失 | 光线不足或距离太远;表情页可适当调低 `TH` 里的阈值 |
| 轻松崩住里表情包不显示 | `memes/` 文件夹要和网页放在同一个文件夹;自己加图后,记得把文件名补进 `meme.html` 的 `MEME_FILES` 数组(图片全加载失败时,游戏会自动改用代码现场画的"抽象卡",不会报错) |
